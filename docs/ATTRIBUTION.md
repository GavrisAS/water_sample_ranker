# Происхождение кода

Базовая реализация `gdis_loader` предоставлена пользователем для адаптации.
Авторство исходного проекта сохранено в локальном эталоне. Владелец подтвердил
права на публичное распространение адаптированного кода и производного шаблона,
включая оформление корневого образца (Stage B.1). Отдельная лицензия для стороннего
переиспользования не назначается автоматически; новая лицензия не выдумывается.

Перенесены с заменой namespace: `domain/dates.py`, модели provenance/фонда/истории,
`matching/normalize.py`, `fund_scope.py`, `lifecycle.py`, `readers/common.py`,
`fund.py`, `well_history.py`, `progress.py`; адаптированы синтетические тесты
normalization, partial dates, fund reader. В фонд включены все C/D/G/H,
добавлен cutoff дат. GDI-specific типы заменены узким IdentityObservation.

GUI воспроизводит LoaderWindow: сетка, порядок действий, worker QObject/QThread,
валидационный gate, progress, status. Конфигурация, CLI, service, Excel writer и
Windows workflows адаптируют проверенные принципы, но реализованы для новой схемы.
LHA reader и политика пар написаны заново: целые наблюдения, конфликт дубликатов,
никакого максимума независимых метрик и никакого перехода через неполную пробу.

Не перенесены GDIS criteria/rules/transforms, active-only eligibility, μ/λ,
старые веса, gas debit, фиктивное «Нет» для ГТМ. Текущий пласт определяется
сначала фондом и датированной Base-историей. Summary GDI — дополнительное evidence.

Корневой XLSX — предоставленный пользователем UX-образец; новый шаблон получен
его очисткой и заменой модели (см. EXCEL_TEMPLATE_AUDIT.md). Исходники не изменяются.
