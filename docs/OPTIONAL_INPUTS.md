# Необязательные источники Stage C

Мониторинг фактических штуцеров — необязательная диагностика. Значения открытия
регулятора не доказывают диаметр в мм. Для подтверждённого увеличения доступна
ручная таблица Excel с датой, диаметрами и основанием.

План ГТМ и геоданные исключены из видимого GUI и help. Старые ключи `gtm_plan`
и `geodata` / флаги `--gtm-plan`, `--geodata` принимаются для совместимости,
игнорируются с диагностикой `deprecated_inputs_ignored`; файлы не открываются
и не ищутся автоматически. Исторический JSON reader сохранён для архивных
тестов; глубоко вложенный JSON отклоняется fail closed на Python 3.14.

Ручной ГТМ задаётся в Excel. `--manual-input` принимает предыдущую книгу или
явно выбранный каталог предыдущего пакета. Никакого поиска операторских книг
в production data не выполняется. При конфликтах новая копия не публикуется.
