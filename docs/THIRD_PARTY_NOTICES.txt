The onedir uses shared DLLs in _internal/. To use a compatible modified library,
keep an original backup outside this folder, replace the relevant DLLs/bindings
with ABI-compatible builds for the same Windows x64 / Python 3.14 / Qt version,
and start the application again. Rebuild instructions for a complete new bundle
are scripts/build_windows.ps1 in the public source repository. No runtime gate
prevents library replacement. Reverse engineering needed to debug modifications
to these LGPL libraries is permitted. Release checksums describe the original
distributed files; changed libraries naturally have different hashes.
